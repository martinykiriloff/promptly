It wraps Claude Code. It doesn't replace it.

Nothing is forked or patched, so every new Claude Code release works on day one.

  1. Start a session

    Press ⌘N. Claude Code runs exactly as it does in your terminal, in its own worktree if you like.

  2. Promptly listens

    Session hooks, the status line and the transcript tell it when Claude is working, waiting, finished, or spending.

  3. You step in

    The session turns amber and rises to the top. Press ⌘J to jump straight to it.

Tech specs

Compatibility
macOS 14 or later on Apple silicon. Linux x86_64 and arm64, Wayland and X11. Works with any shell and any CLI.
Claude Code
Runs the unmodified claude CLI. Session-scoped hooks and status line; your own hooks and status line keep running. Verified with 2.1.286.
Terminal
GPU rendering with Metal and Vulkan. Truecolor, Kitty keyboard protocol, OSC 8 links, bracketed paste, 100,000 lines of searchable scrollback. Shell integration for zsh, bash and fish.
Sessions
Attention queue and notifications, git worktree per session, fan‑out, review with comments, composer, history search and resume, command palette, scripting with promptly-ctl.
Security
Local Unix sockets only, each with a 256‑bit token and peer check. Clipboard reads blocked. Paste preview for hidden characters. Never approves on your behalf.
License
FSL-1.1-MIT. Use it, read it, change it. You can't sell a competing product with it, and every version becomes MIT two years after release.
Updates
Updates itself from GitHub Releases. Every download is checked against a published SHA‑256 before install.

Download Build from source
Install from the command line 
# Mac: unzip, clear the quarantine flag once, open
unzip Promptly-*-macos-arm64.zip -d /Applications
xattr -dr com.apple.quarantine /Applications/Promptly.app
open /Applications/Promptly.app
# Debian and Ubuntu
sudo apt install ./promptly_*_$(dpkg --print-architecture).deb
# From source
git clone https://github.com/martinykiriloff/promptly.git && cd promptly
cargo build --release --workspace && ./target/release/promptly

Every build is listed with its checksum on the releases page.
