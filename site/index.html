It wraps Claude Code instead of replacing it

Nothing is forked or patched, so every Claude Code release works on day one. Promptly listens on the side and turns what Claude does into something you can act on.

  1. Start a session

    Press ⌘N. The unmodified claude TUI runs through your login shell, in its own git worktree if you want one.

  2. Promptly listens

    Session-scoped hooks, the status line feed and the transcript tell it when Claude is working, waiting, finished, or spending.

  3. You get pulled in

    The session turns amber, joins the Needs you queue and sends a notification. ⌘J takes you straight there. Approving is still yours.

Built for running agents in parallel

See your plan usage as it moves

Claude Code reports your 5-hour and weekly limits to its status line. Promptly turns them into meters that sit in the sidebar and count down to the reset.

  • Limit alerts when either window passes 80% and 95%
  • Spend and burn rate across open sessions, per hour
  • Today's tokens across every Claude session on the machine, by hour and model

Review without leaving the terminal

The diff pane follows the session you're looking at and refreshes when Claude edits a file. Click a line to comment, then send every comment back to the session as one prompt.

  • Unified or split diffs, untracked files included
  • Worktree per session, so parallel agents never collide
  • Fan out a task list into one session per task

Everything is one keystroke away

Every action lives in the command palette and every shortcut can be rebound. Search past conversations across all your projects and reopen one with its full history.

  • Composer for long prompts, with @file completion
  • Resume any past session by text or folder
  • promptly-ctl to script sessions from Makefiles and git hooks

Install

Promptly needs Claude Code on your PATH. After the first install it updates itself from GitHub Releases and checks every download against a published checksum.

macOS builds aren't notarized yet. Clear the quarantine flag once after unzipping, as shown.

# Download the latest build, then:
$ unzip Promptly-*-macos-arm64.zip -d /Applications
$ xattr -dr com.apple.quarantine /Applications/Promptly.app
$ open /Applications/Promptly.app
# Debian / Ubuntu (x86_64 or arm64)
$ sudo apt install ./promptly_*_$(dpkg --print-architecture).deb

# Any distro: unpack and run; updates itself in place
$ tar -xzf promptly-*-linux-$(uname -m | sed s/aarch64/arm64/).tar.gz
$ ./promptly
$ git clone https://github.com/martinykiriloff/promptly.git
$ cd promptly
$ cargo build --release --workspace
$ ./target/release/promptly

All builds are on the releases page, with SHA256SUMS.
